# gem の責務を汎用の CIBA OP 拡張に限定する

公開 gem は rodauth-oauth に CIBA の OP 機能を追加する。初期導入先の承認・委譲フロー全体を gem に組み込む案に対し、他の導入先でも利用できる境界として、本人確認・承認・監査記録を導入アプリへ接続する拡張点を提供する方針とする。拡張点の具体的な契約は今後決定する。

Okta を上流 IdP とする CS 認証、サポートアカウントへの委譲、セッションと個別操作それぞれの承認条件、実操作の監査記録は導入アプリの責務とする。CIBA の顧客認証結果と委譲後のトークンは分離し、委譲に Token Exchange を利用するかはこの gem の設計では決定しない。

顧客への通知、顧客向けログイン・承認画面も導入アプリが提供する。gem はアプリから認証・承認結果を受け取り、要求対象との一致、期限、二重完了を検証して、要求の状態とトークン発行を管理する。

結果の受け渡しには Ruby API を提供する。HTTP などのトランスポートはアプリケーションの要求に従って選択するものであり、gem は独自の承認完了 HTTP API を必須にしない。
