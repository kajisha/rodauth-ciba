# CIBA Core 1.0 要件監査（2026-09-29の初期範囲）

これは初期の poll/login_hint 構成の監査スナップショットです。その後に実装した任意機能や現在のテスト環境を表すものではありません。[現行の対応表](protocol-coverage.md)と[整合化計画](alignment-roadmap.md)を参照してください。拡張後の再監査は[現行差分](requirements-audit-current.md)で進行中です。全規範要件の確認は未完了です。

2026-09-29。Jev評価用カタログの159評価単位を、初版の適用範囲・責務・コードとテストの証拠で再分類した。159は仕様の公式要件数ではなく、参照先OIDC/RFCを含む全規範文の網羅性を保証しない。点数・確率は合否根拠にしない。

初版: poll / login_hint / public subject / static registration。署名付き認証要求、user_code、ping/push、その他hint、pairwiseは適用外。JWT client authenticationは署名付き認証要求とは別。

`verified`は記載テストで対象挙動を確認、`code_review_only`はコード根拠のみ、`app_contract`は導入アプリ・運用を含む契約、`client_only`はClientの責務、`optional_excluded`は機能の適用条件が初版で成立しない項目。完全適合やすべての設定での動作保証ではない。規範強度はMUSTの有無だけでなく、パラメータ・応答の定義と適用条件を含めて読む。

判定集計: app_contract: 7, client_only: 13, code_review_only: 1, optional_excluded: 70, verified: 68。

詳細な要件文・条件・証拠の限界は[JSON](requirements-audit.json)、再現した問題と検証環境は[セキュリティレビュー](security-review.md)。この監査時点のテストはRuby 4.0.6 / SQLiteで、PostgreSQL/MySQLはDocker権限制約により未検証だった。その後の実行結果は[release validation](release-validation.md)に記録する。
