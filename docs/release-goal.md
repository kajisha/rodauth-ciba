# 0.1.0 公開準備のゴールと到達点

2026-09-29に開始。2026-09-30に初版の公開範囲と検証記録を整理。
このゴールは配布物の準備であり、RubyGemsへの公開はまだ実施していない。

## 初版の範囲

基本構成は poll・login_hint・public subject・静的クライアント登録。
既存OP全体の認証方式は制限せず、CIBAでは登録済みconfidential clientを要求する。
JWTクライアント認証を含むupstream連携と、任意機能の範囲は
[README](../README.md)および個別の機能文書を正とする。
当初の「basic/postのみ」「署名要求や他hintは未実装」という制限は撤回済み。

refresh・pairwise・CIBA動的登録は実験的機能として同梱するが、既定では無効で、
初版のサポート範囲には含めない。pushと暗号化ID Token hintは未実装。
UI・通知の業務フロー・上流認証・委譲・業務認可はアプリ側の責務。

## 検証する成果

- Discovery・要求検証・認証・エラー・期限・一度だけの発行を仕様とテストに対応付ける。
- 完了API・保存済み同意・競合・フック・ロールバック・観測イベントを検証する。
- Ruby 3.3/3.4/4.0、SQLite/PostgreSQL/MySQLの実行結果を記録する。
- 設定・migration・運用・サンプル・既知の制約を配布物に含める。
- gemをビルドし、checkout外への一時インストールからスモークテストを実行する。
- 公開前のコード整理とメタデータを確認し、未検証範囲を残す。

現在の判定は[公開前確認](release-readiness.md)、過去の検証結果は
[公開検証履歴](release-validation.md)を参照。テスト件数やモデルのconfidenceだけを
公開条件にはしない。認定取得や完全な任意機能の組み合わせ保証は目標ではない。
